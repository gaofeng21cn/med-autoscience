# DeepScientist 方法学习

本文只负责从 DeepScientist 学习方法时的来源与采纳判断，不替用户扩大任务授权，也不要求维护旧 MDS fork。

长期值得比较的是研究合同、可恢复的 artifact/decision 记录、baseline 刷新、bounded analysis、独立 review、失败路线学习和人类接管语义。来源是外部方法输入，当前医学事实与实现仍由 MAS contracts、Stage pack、ScholarSkills 和实际 owner evidence 决定。

一次学习先读明确的 source/ref 与对应变化，判断其解决了哪个当前问题。医学方法进入 MAS Stage/knowledge/quality policy 或 ScholarSkills；通用 runtime、恢复、工具与 UI 进入其平台 owner。没有可证收益时可记录不采纳理由，不为留下审计页而制造工作。

采纳结果须保留来源与许可、语义变化、接收 owner 和验证证据。原样引用、clean-room 方法重写和 MAS 自己的规则应明确区分。历史 upstream 已实现不意味着当前 MAS 已实现；文档、test、真实 study 和 production evidence 各只证明自身范围。

不复制外部 runtime、provider/credential store、scheduler、工作台或质量 owner；不把外部 checkpoint、paper screenshot、rank 或自评作为 MAS ready verdict。具体代码/文档变更及推送范围由本次用户请求决定，不能从“看看更新”自动推导生产操作或额外仓库写入。

历史来源说明见 [来源辨析](./med_deepscientist_upstream_source_provenance.md)；当前采用情况以代码和 [能力映射](../../../contracts/capability_map.json) 为准。
