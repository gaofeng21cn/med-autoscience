# MAS 理想目标态

Machine boundary: 本页定义长期研究效果，不声明当前实现或真实论文完成。

## 研究目标

MAS 应让单人研究者从临床问题与实际数据出发，持续形成可审阅的证据、
明确受限的 claim、可复现分析、医学稿件和可追溯交付。
Agent 自主选择方法与工具，并在每个有意义的产物上留下来源、判断和失败经验。
人类只在缺失关键事实、真实权限、价值判断或不可逆提交边界介入。

## 理想体验

研究者能直接看见当前问题、证据变化、质量债、下一 owner 和需要自己的决定。
暂停、里程碑交付和停止不会被历史 runtime 或 telemetry 覆盖；
论文 trajectory、运行状态与实际用量分别可追溯。
工作区经验可以被后续研究按需检索，不能成为 route scorer 或复制的全量 prompt。

## 可验收的结果

- 不同 study 类型都能形成严谨且医学可读的稿件，避免重复同一种历史返工。
- 负结果、失败假设、route-back 与修订保留可消费 evidence，普通缺口不会无限循环。
- 独立 Review、artifact currentness、修订消费和 publication authority 在真实论文中成立。
- Package、executor 和 App 可各自演进，研究 identity 与领域事实保持连续。
- 数据资产、memory、artifact 保留和恢复可在实际 workspace 被验证。
