# Publication Strategy Memory Policy

The [library](../../../agent/knowledge/publication_strategy_library.md) owns reusable research strategy bodies. OPL owns the shared catalog and scoped recall; [MAS knowledge policy](../domain_memory_markdown_first_policy.md) defines the domain's placement and acceptance rules.

Use relevant patterns to compare fit, evidence requirements, analysis and display choices, claim limits, reviewer risks and stop conditions. Clinical endpoints, cohorts and actual study results must come from current study evidence. A pattern cannot choose a winning hypothesis or authorize publication.

Store an individual paper's decisions in its project memory. A reviewed lesson that applies across papers may enter workspace shared memory; a reusable, non-private method can be proposed for the versioned Agent knowledge pack. Include supporting and failed-path evidence, scope and review dates. MAS retains semantic acceptance; OPL validates catalog structure, body identity and consumption receipts.

Maintain one canonical body per lesson. Supersede an obsolete entry and record its replacement; use the shared lifecycle instead of copying Agent seed packs into workspaces.
