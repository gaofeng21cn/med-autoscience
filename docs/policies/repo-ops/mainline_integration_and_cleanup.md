# 主线集成与工作区清理

本文只定义源码变更的本地集成和自有临时工作区收尾；运行中 study 的变更见 [运行面切换](./merge_and_cutover_gates.md)。

每个写集只有一个 owner。开始时读取当前 Git 状态与其他活跃任务；复杂或可能重叠的改动使用独立 worktree，不覆盖已有未提交内容。任务范围、授权和用户要求决定提交、主线集成与推送终点。

提交前复核实际 diff，并运行 [对应验证入口](./repository_ci_preflight.md)。集成到更新后的主线若产生冲突或改变被验证行为，只重跑受影响检查。不要为相同字节反复新建 integration worktree 和重复完整测试。

集成后用 Git readback 证明目标分支包含本次结果；本地提交、主线包含和远端发布是不同状态。只有用户要求推送时才把外部远端作为终点。

自有临时 worktree 和 branch 在结果已吸收、没有未保存内容、没有活动执行者且不存在其他 owner 使用后清理。用当前 `git worktree list`、分支包含关系与实际任务状态判定；不依据旧前缀保护表、历史 mailbox、已退役 registry 或文档中的完成标签决定删除。
