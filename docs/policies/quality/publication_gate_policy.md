# Publication Gate Policy

Owner: `MedAutoScience`
Purpose: `publication_acceptance_boundary`
State: `active_policy`
Machine boundary: 独立 Review、currentness evaluation、MAS owner result 与 publication generation 持有验收事实。

Publication acceptance 必须消费当前研究 identity、完整 evidence/claim lineage、
独立 Stage Review 与跨 Stage Meta Review，以及与交付 generation 绑定的 exact bytes。
产物存在、gate checklist 完整或运行成功不能签发 ready。

普通质量缺口允许形成可消费 draft 或质量债，并路由到最早能修复的 Stage；
不以 scout、首个结果或写作前的固定门禁阻止所有推进。
弱结果必须诚实降级 claim、调整研究路线或保留负结果，而不能通过论文包装增强结论。

Final Handoff 仅封装已审阅产物，发现内容缺陷时 route-back。
外部投稿仍需相应作者事实、期刊要求和明确 human authority。
操作流程见 [Submission Revision](../study-workflow/submission_revision_operating_contract.md)。
